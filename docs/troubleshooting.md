\# Troubleshooting



\## Pods Stuck in Pending



\### Cause



Calico networking had not been installed.



\### Resolution



Installed Calico CNI and verified all system Pods entered the Running state.



\---



\## SSH Configuration



\### Cause



Native SSH configuration was not initially configured correctly.



\### Resolution



Configured the SSH client and verified successful authentication from Windows Terminal.



\---



\## Rolling Update



\### Observation



A new ReplicaSet appeared after updating the Deployment image.



\### Explanation



Deployments create a new ReplicaSet during rolling updates while retaining the previous ReplicaSet for rollback.



\---



\## Exported YAML



\### Problem



The exported manifests contained runtime metadata generated by Kubernetes.



\### Resolution



Removed fields such as status, uid, resourceVersion, managedFields, and creationTimestamp to create reusable manifests suitable for Git.
